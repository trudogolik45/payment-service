# Платёжный сервис

Принимает платежи от клиентов, проводит их через платёжный шлюз и уведомляет клиента о результате.

## Язык

**Платёж**:
Просьба клиента перевести сумму в одной из валют. Статус платежа: ожидает, успешен или отклонён.
_Избегать_: транзакция, заказ

**Ключ идемпотентности**:
Ключ, который клиент присылает вместе с созданием платежа. Повтор с тем же ключом возвращает уже созданный платёж.
_Избегать_: request id, ключ к шлюзу

**Списание**:
Один вызов платёжного шлюза по платежу. Ключом к шлюзу служит идентификатор платежа, а не ключ идемпотентности клиента.
_Избегать_: charge, проведение, оплата

**Уведомление**:
Сообщение клиенту на его webhook URL о результате списания. Может прийти больше одного раза.
_Избегать_: callback, нотификация

**Обработка**:
Списание и затем уведомление по одному платежу.
_Избегать_: процессинг, исполнение

**Событие outbox**:
Запись о факте «платёж создан». Она сохраняется вместе с платежом и затем публикуется в очередь.
_Избегать_: сообщение, задача
